# 高千穂峡ボート 自動搶位與預約 Chrome 擴充功能

專為 **高千穂峡貸しボート（eipro.jp）** 線上預約系統打造的專屬 Chrome 擴充功能（Manifest V3）。

解決手動搶票秒殺與信用卡 3D Secure 驗證的痛點：
1. **開賣瞬間自動鎖位 (`hold_slot`)**：在 08:00:00 前 0.5 秒密集發送請求，取得伺服器 **15 分鐘臨時席位保留權**（仮押さえ）。
2. **秒速自動填寫表單 (`orders/add`)**：帶同一個瀏覽器 Session Cookie 進入填表頁，0.3 秒自動填入代表者姓名（漢字與片假名）、電話、Email、地址、大人/幼兒人數及信用卡資料。
3. **無縫銜接 3D 驗證聲響警報**：完全在您的本機桌面 Chrome 瀏覽器內執行，跳轉至銀行 3D 驗證頁面時自動發出**高頻蜂鳴警報聲**，提醒您直接在桌面上輸入簡訊驗證碼（OTP）完成付款！

## 🚀 一、 如何在 Chrome 安裝擴充功能（未封裝模式）

1. 開啟 Google Chrome 瀏覽器。
2. 在網址列輸入並前往：
   ```text
   chrome://extensions/
   ```
3. 在右上角開啟 **「開發人員模式 (Developer mode)」** 開關。
4. 點擊左上角的 **「載入未封裝項目 (Load unpacked)」** 按鈕。
5. 選擇本專案目錄中的 `chrome_extension` 資料夾：
   ```text
   /Users/ych/takachiho_crawler/chrome_extension
   ```
6. 安裝完成後，Chrome 工具列右上角會出現藍色小船圖示 **「高千穂峡ボート 預約助手」**。建議點擊「圖釘」圖示固定在瀏覽器工具列。

## ⚙️ 二、 設定代表者與信用卡資料

點擊工具列的擴充功能圖示開啟設定面板：

### 1. 預約時段設定
* **目標日期**：預設為 `2026/11/07`
* **船班時段**：例如 `08:30:00`（支援 08:30 ~ 16:30 各時段）
* **大人人數**：`1` ~ `3` 名（上限 3 人，小學生以上算大人）
* **幼兒人數**：`0` ~ `1` 名（未就學兒童）
* **開搶啟動時間**：預設 `07:59:59.500`（台灣時間 08:00 前 0.5 秒開始密集重試鎖位）
* **自動鎖位 / 自動填表 / 自動送出**：皆預設開啟

### 2. 代表者個人資料
* **姓 / 名**：漢字或護照英文姓名（例如：`王` / `大明` 或 `WANG` / `DAMING`）
* **姓 / 名 (フリガナ)**：全形日文片假名（例如：`ワン` / `ダイミン`）
* **電子郵件信箱**：接收預約憑證與通知信（例如：`your_email@gmail.com`）
* **聯絡手機**：台灣或日本手機（例如：`+886912345678`）
* **出生年月日**：格式 `YYYY/MM/DD`（例如：`1990/05/20`）
* **郵遞區號 / 日本住址**：預設已填入高千穂當地或可改為您住宿的日本飯店地址

### 3. 信用卡資料 (PayJP 付款)
* **卡號**：16 碼純數字
* **到期年月**：MM / YY
* **安全碼 (CVC)**：3 或 4 碼
* **持卡人姓名**：英文大寫（例如：`DAMING WANG`）

> 🔒 **隱私保證**：所有個人與信用卡資料僅安全保存在您電腦的 `chrome.storage.local`，絕不對外傳輸。

設定完成後，點擊 **「💾 儲存所有預約設定」**。

## 🛠️ 四、 懸浮面板快捷按鈕功能說明

造訪 `https://eipro.jp/takachiho1/*` 任意頁面時，右上角會常駐懸浮面板：
* **⚡ 一鍵立即搶位 (Hold Slot)**：若想手動提前或隨時測試鎖位，點擊此按鈕會立即發送請求。
* **✍️ 一鍵填表**：在任何預約表單頁面點擊，立即填入所有個人與信用卡資料。
* **📋 複製卡號 / 複製到期日 / 複製 CVC**：若遇到銀行沙盒或特殊的 iframe 欄位，可直接 1 鍵複製對應資訊快速貼上。
* **🔊 測試音效**：測試瀏覽器的 Web Audio 音效合成器是否正常發聲。
* **− / +**：收合或展開面板，避免遮擋網頁內容。
