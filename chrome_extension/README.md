# 高千穂峡ボート 極速佔位 Chrome 擴充功能 (Takachiho Boat Helper)

專為 **高千穂峡貸しボート（eipro.jp）** 線上預約系統打造的專屬 Chrome 擴充功能（Manifest V3）。  
**當前版本：v1.0.2**（全面強化日期切換防呆、跨時段保護與除錯日誌匯出機制）

---

## 🎯 核心哲學：全力搶下席位（仮押さえ），取得 15 分鐘保留權！

在 eipro.jp 的預約機制中，**搶座位的勝負完全在於「開賣第 0 毫秒誰先拿到 `hold_slot`」**：
* 只要搶下 `hold_slot`（伺服器回應 `result: "1"`），伺服器會**為您獨占保留席位整整 15 分鐘**！在這 15 分鐘內，全日本沒有任何人能搶走這艘船。
* 進到預約輸入頁面後，畫面上方會顯示倒數計時（例如 `残り14分59秒`），您有非常充裕的時間在電腦前仔細核對姓名、手機、地址與信用卡資料，完全不需要手忙腳亂。
* 因此本擴充功能的唯一目標：**以毫秒級波浪連發，在開賣瞬間第一個把位子佔下來！**

## 🚨 v1.0.2 重大更新與防呆機制解析

### 1. 為什麼先前會出現「⚠️ 予約枠が存在しません。」？
在舊版中，若您切換了「目標日期」（例如改為 `2026/10/26` 實測），但：
1. **舊切換按鈕未自動儲存**：僅修改了表單數值，使用者若未滾到底部點擊「儲存搶位設定」，設定不會寫入瀏覽器。
2. **Session 代碼跨期錯配**：外掛讀取時使用了 11/07 的專屬連結（內含 `service_session_cd=68a916a6...`），把 11/07 的 Session 代碼拿去請求 10/26 的時段，eipro 伺服器因參數不合直接判定該預約席位不存在（`予約枠が存在しません`）。
3. **分頁未即時重置**：分頁在收到設定更新時，未清空舊的 Session 緩存，導致畫面上顯示 10/26 但背景依舊使用 11/07 的代碼。

---

### 2. v1.0.2 導入的四大防呆與除錯重構

* **🛡️ 防呆 1：日期切換按鈕「一鍵聯動 + 自動儲存」**
  * 點擊 **`🧪 切換 10/26 實測時段`** 或 **`🎯 切換 11/07 正式搶票`** 時，系統會**同時聯動**「目標網址」、「目標日期」、「目標時段」與「對應 Session 代碼」。
  * **點擊即自動儲存**至 `chrome.storage.local`，並即時透過 Runtime Message 推送給所有開啟的分頁，徹底告別「忘了按儲存」的人為疏失！
* **🛡️ 防呆 2：網址與日期一致性即時校驗**
  * 若手動變更了目標日期，系統會即時比對目標網址內的 `service_start_datetime`。
  * 若發現「網址日期」與「目標日期」不一致，介面會**立刻彈出醒目的紅色防呆警告**，提醒使用者點擊按鈕重置。
* **🛡️ 防呆 3：Session CD 跨時段嚴格隔離**
  * `content.js` 在解析 Session 代碼時，會比對該網址內的日期。**若日期與當前目標日期不符，堅決拒絕沿用**！
  * 發送 `hold_slot` 鎖位前，若 Session 代碼未確定，會精準比對目標日期（10/26 或 11/07）指派其專屬代碼；若為未知的日期且無法解析，會**主動安全停止**，絕不拿錯誤代碼去碰撞伺服器。
* **📋 除錯日誌（Debug Logs）支援「一鍵下載為 .log 檔案」**
  * **Popup 與 網頁 HUD 雙向整合**：無論在設定彈出視窗還是活動頁面右上角，都能隨時展開查看最近執行的每一條動作（解析步驟、發送毫秒數、伺服器原始回應）。
  * **一鍵下載檔案**：點擊 **`📥 下載 .log 檔案`** 按鈕，瀏覽器會直接產生包含時間戳記的 `.log` 純文字檔存入您的「下載項目」資料夾，發生問題時可直接將該檔案提供開發者秒速定位！
  * **一鍵複製文字**：支援點擊「📋 複製文字」直接將日誌複製到剪貼簿。

## ⏱️ 網路延遲實測與發送時機解析

* **網路單向傳輸時間（One-way Latency）**：台灣 ⇄ 日本 eipro 伺服器約 **20ms ~ 35ms**。
* **為什麼提早 15ms 是最佳發送點？**
  * 若開賣時間為 `08:00:00.000`，外掛設定在 `07:59:59.985` 發出第一發請求：
    $$\text{07:59:59.985} + \text{20ms (網路耗時)} = \mathbf{08:00:00.005} \quad 🎯$$
  * 封包將於開賣瞬間後 **5 毫秒** 精準抵達伺服器，既避開開賣前的「尚未開放」拒絕，又領先絕大多數人工與其他腳本！
* **250ms 安全重試節奏**：
  * 若伺服器系統時間有微小落後（開賣瞬間前幾毫秒回傳未開放），外掛會以 **250ms 溫和節奏** 重送（最多 12 次，約 3 秒）。
  * 擬真人極限手速，完全不會觸發雲端 WAF 或遭伺服器視為惡意攻擊封鎖 IP。

## 🚀 3 步驟安裝與使用教學

### 步驟 1：載入擴充功能至 Chrome
1. 打開 Chrome 瀏覽器，在網址列輸入並前往：
   ```text
   chrome://extensions/
   ```
2. 開啟右上角的 **「開發人員模式 (Developer mode)」**。
3. 點擊左上角 **「載入未封裝項目 (Load unpacked)」**。
4. 選擇本專案目錄：
   ```text
   /Users/ych/takachiho_crawler/chrome_extension
   ```
5. 確認版本顯示為 **v1.0.2**。
6. 點擊瀏覽器工具列右上角的小拼圖圖示，找到小船圖示並點擊圖釘 📌 固定在工具列。

---

### 步驟 2：選擇搶位時段（一鍵切換）
點擊工具列的小船圖示打開設定面板：

1. **若是要在搶票日前演練測試（例如模擬搶 10/26 船班）**：
   * 點擊黃色按鈕：**`🧪 切換 10/26 實測時段 (點擊自動切換並儲存)`**。
   * 面板會自動更新網址、日期為 `2026/10/26`、時段為 `08:30:00`，並**自動儲存**！
2. **若是要在 10/24 早上正式搶 11/07 船班**：
   * 點擊藍色按鈕：**`🎯 切換 11/07 正式搶票 (點擊自動切換並儲存)`**。
   * 面板會自動更新網址、日期為 `2026/11/07`、時段為 `08:30:00`，並**自動儲存**！
3. 確認黃色預覽文字顯示：
   `🎯 首發發動時間：07:59:59.985（提前 15ms 命中開賣瞬間，未開則 250ms 安全重試）`。

---

### 步驟 3：搶票當天（早上 07:55）標準操作流程（SOP）

1. **07:55 打開專屬活動網址**：
   * 點擊擴充功能選單中的 **「🌐 開啟此目標網址」**（或點擊網址直接前往）。
   * **⚠️ 重要提醒：請務必停留在專屬活動頁面（`events/view/EV00000007?...`），不要停留在日曆週表示頁！**
2. **確認右上角懸浮面板**：
   * 頁面右上角會出現 **【🛶 高千穂峡ボート 搶位助手 v1.0.2】** 面板。
   * 核對面板資訊：
     * **目標時段**：`2026/11/07 08:30`（正式）或 `2026/10/26 08:30`（演練）
     * **搶位發動時間**：`07:59:59.985 (提前 15ms)`
     * **Session 代碼**：正常顯示非空白代碼
     * **狀態**：`🟢 待命中`
3. **07:59:59.985 全自動發動**：
   * 當毫秒時鐘倒數至發動時間，助手將自動送出首發請求，並以 250ms 安全重試。
   * 若頁面上出現「予約手続き」按鈕，助手的 MutationObserver 也會同步以 0 毫秒極速自動點擊（雙軌防護）。
4. **搶位成功（15 分鐘保留期啟動）**：
   * 鎖位成功後，助手會自動播放勝利音效（三全音鈴聲）。
   * 狀態變為 `🎉 席位鎖定成功！獲得 15 分鐘保留期！`。
   * 頁面將在 0.3 秒內自動帶入同 Session 進入 `orders/add` 預約輸入頁！
5. **悠閒填寫資料並送出**：
   * 進入預約頁面後，畫面上方會顯示倒數 `残り14分59秒`。
   * 請在電腦前從容填寫代表者姓名、電話、地址、人數與信用卡資料。
   * 點擊「入力確認」送出後，若跳轉至銀行 3D 簡訊驗證頁面，輸入手機驗證碼即可完成訂位！

## 🛠️ 除錯日誌匯出與問題排除指南

若操作過程中遇到任何疑慮，請依照以下步驟匯出 Log 記錄：

1. **如何下載 Log 檔案**：
   * **方式 A（推薦）**：點擊 Chrome 工具列的小船圖示，展開底部的「📋 執行日誌與除錯」，點擊 **`📥 下載 .log 檔案`**。
   * **方式 B**：在預約網頁右上角助手面板中，展開「📋 即時除錯日誌」，點擊 **`📥 匯出 .log 檔案`**。
   * 產生的檔案名稱如 `takachiho_helper_20261012_215500.log`，會直接存入「下載項目」資料夾。
2. **常見訊息說明**：
   * `result=1`：🎉 席位鎖定成功！
   * `予約枠が存在しません`：Session 代碼與該日期時間不符，或該時段不存在。請點擊切換按鈕重新帶入相符時段。
   * `予約が定員数に達しています`：該時段已被其他人在毫秒間搶購一空（額滿）。
   * `この枠は予約受付が開始されていません`：伺服器尚未開放預約（代表尚未到 08:00:00.000）。
