# 高千穂峡ボート 極速佔位 Chrome 擴充功能 (Takachiho Boat Helper)

專為 **高千穂峡貸しボート（eipro.jp）** 線上預約系統打造的專屬 Chrome 擴充功能（Manifest V3）。

## 🎯 核心哲學：全力搶下席位（仮押さえ），取得 15 分鐘保留權！

在 eipro.jp 的預約機制中，**搶座位的勝負完全在於「開賣第 0 毫秒誰先拿到 `hold_slot`」**：
* 只要搶下 `hold_slot`（`result: "1"`），伺服器會**為您獨占保留席位整整 15 分鐘**！在這 15 分鐘內，全日本沒有任何人能搶走這艘船。
* 進到預約輸入頁面後，畫面上方會顯示倒數計時（例如 `残り14分05秒`），您有非常充裕的時間在電腦前仔細核對姓名、手機、地址與信用卡資料，完全不需要手忙腳亂。
* 因此本擴充功能的唯一目標：**以毫秒級波浪連發，在開賣瞬間第一個把位子佔下來！**

## ⏱️ 網路延遲實測與發送時機解析

很多搶票外掛常犯的錯誤是：**只發單一次請求，且發送時機不對**。

### 1. 網路耗時實測數據（台灣 ⇄ 日本 eipro 伺服器）
* **網路單向傳輸時間（One-way Latency）**：約 **20ms ~ 35ms**（0.02 秒）。
* **伺服器後端處理時間（Server PHP & DB Processing）**：約 **200ms ~ 300ms**。
* **整個來回時間（RTT）**：約 **350ms**。

### 2. 為什麼「開賣前 0.5 秒只發單一發」會失敗？
* 若開賣時間為 `08:00:00.000`，如果您在 `07:59:59.500` 送出請求，封包在 **`07:59:59.525`** 就已抵達日本伺服器！
* 伺服器系統時間此時尚未到 08:00:00，會直接認定為尚未開賣而拒絕（`この枠は予約受付が開始されていません。`）。如果只發這一發就停，就會錯失良機！

### 3. 為什麼「等到 08:00:00 才按」也會輸？
* 根據 10/10 與 10/11 的實際監控，船班在開賣後 **3 ~ 5 秒內就被全數秒殺**。
* 如果等到 08:00:00.000 才開始觸發，加上網路 25ms 與伺服器排隊延遲，抵達時早已落後給其他競爭者。

### 4. 終極致勝解法：🎯 首發提前 15ms 精準命中 + 250ms 安全重試
為了避免過早發送被系統拒絕，同時杜絕頻繁請求觸發 WAF 或 IP 封鎖，小幫手採用**精準首發 + 溫和安全重試**策略：
* **首發時間點**：開賣前 15 毫秒（`07:59:59.985`）發出第一發 `hold_slot`：
  * `07:59:59.985` + 20ms 單向網路傳輸 = **`08:00:00.005`** 🎯
  * 封包於開賣瞬間過後的第 5 毫秒精準抵達伺服器！
  * 完美避開 08:00:00 前的「尚未開放」拒絕，並領先所有人類與其他腳本！
* **安全重試間隔**：若伺服器時間有些微落後而尚未開放，小幫手以 **250ms 溫和節奏** 重送（最多 12 次，約 3 秒）：
  * 250ms 相當於極限手速點擊，100% 擬真人節奏，完全不用擔心被伺服器誤判為惡意攻擊。
* **只要成功取得 `result: "1"`**：
  * 立即終止後續所有重送！
  * 播放勝利音效，彈出保留 15 分鐘通知！
  * 0.4 秒內自動帶同 Session 進入 `orders/add` 預約頁面！

## 🚀 3 步驟安裝與使用教學

### 步驟 1：載入擴充功能至 Chrome
1. 打開 Chrome 瀏覽器，網址列輸入並前往：
   ```text
   chrome://extensions/
   ```
2. 開啟右上角 **「開發人員模式 (Developer mode)」**。
3. 點擊左上角 **「載入未封裝項目 (Load unpacked)」**。
4. 選擇目錄：
   ```text
   /Users/ych/takachiho_crawler/chrome_extension
   ```
5. 點擊瀏覽器工具列上的小船圖示，並點擊圖釘 📌 固定在工具列。

---

### 步驟 2：設定目標連結與開搶時機
點擊工具列的小船圖示開啟設定面板（已預設帶入 11/07 08:30 專屬參數）：
1. **目標預約連結 (Target URL)**：
   * 預設已帶入 11/07 08:30 的專屬直達連結：
     `https://eipro.jp/takachiho1/events/view/EV00000007?closable=1&service_cd=6892dd9d-5b54-4202-bd1d-4aa6c0a8018d&service_session_cd=68a916a6-59c8-459d-9643-a231c0a8018d&service_start_datetime=2026/11/07%2008:30:00&service_end_datetime=2026/11/07%2009:00:00`
   * 亦提供 **「📍 抓取當前分頁網址」** 按鈕，方便隨時抓取任意時段網址。
2. **目標日期與時段**：
   * 日期：`2026/11/07`
   * 時段：`08:30:00` (08:30 - 09:00)
3. **開賣時間與提前發送設定**：
   * 開賣時間：`08:00:00`
   * 提前發送時間：預設 `提前 15 毫秒 (07:59:59.985 - 🎯 推薦！抵達 08:00:00.005)`。
   * 雙軌防護：勾選「到達時間精準鎖位」與「若在活動頁偵測到『予約手続き』按鈕出現，立即毫秒自動點擊」。
4. 點擊 **「💾 儲存搶位設定」**。

### 步驟 3：搶票當天（10/24 早上 07:58）操作流程
1. 點擊擴充功能選單中的 **「🌐 開啟此目標網址」**。
2. 頁面右上角會常駐 **【🛶 高千穂峡ボート 搶位助手】** 懸浮面板，顯示毫秒時鐘與目標時段。
3. 倒數至 **`07:59:59.985`** 時，小幫手首發精準送出，並以 250ms 安全重試！
4. 鎖定成功後，自動播放勝利音效並轉跳至 `orders/add` 預約輸入頁！
5. **您接手輸入**：
   * 畫面上方顯示 `残り14分59秒`，您有整整 15 分鐘安心填寫代表者姓名、電話、地址與信用卡資料。
   * 點擊藍色按鈕 **「入力確認」** 送出。
   * 跳轉至發卡銀行 3D 驗證頁面時，小幫手會自動發出高頻警報聲，提醒您輸入簡訊 OTP 碼完成訂位！
