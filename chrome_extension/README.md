# 高千穂峡ボート 極速佔位 Chrome 擴充功能 (Takachiho Boat Helper)

專為 **高千穂峡貸しボート（eipro.jp）** 線上預約系統打造的專屬 Chrome 擴充功能（Manifest V3）。  
**當前版本：v1.0.3**（全面解決「入力が無効になりました」跳轉表單隱藏問題、瞬斷在途請求、表單自動修復重整機制）

---

## 🎯 核心哲學：全力搶下席位（仮押さえ），取得 15 分鐘保留權！

在 eipro.jp 的預約機制中，**搶座位的勝負完全在於「開賣第 0 毫秒誰先拿到 `hold_slot`」**：
* 只要搶下 `hold_slot`（伺服器回應 `result: "1"`），伺服器會**為您獨占保留席位整整 15 分鐘**！在這 15 分鐘內，全日本沒有任何人能搶走這艘船。
* 進到預約輸入頁面後，畫面上方會顯示倒數計時（例如 `残り14分59秒`），您有非常充裕的時間在電腦前仔細核對姓名、手機、地址與信用卡資料，完全不需要手忙腳亂。
* 因此本擴充功能的唯一目標：**以毫秒級波浪連發，在開賣瞬間第一個把位子佔下來！**

## 🚨 v1.0.3 重大修復：為什麼搶到後跳去「怪怪的地方」？（謎底揭曉與自癒機制）

### 1. 現場實測重現與根本原因（Root Cause）
有使用者回報：「一開始左邊跳有搶到，但網址跳去怪怪的地方（沒有輸入框），後來又不曉得怎麼的跳到填資料的頁面」。經逐格分析錄影：
1. **08:00:02 確實已搶到位子**：小幫手第一時間命中 API，伺服器已將席位保留鎖定在 PHP Session 中。
2. **在途連線與表單點擊衝突**：由於毫秒連發，成功那一瞬間還有其他在途（In-flight）請求正在抵達伺服器，且 DOM 監控同時觸發了 HTML 預約按鈕。
3. **CakePHP Blackhole 攔截**：eipro 系統的 PHP 後端在短時間內接收到並發的表單 POST 與 API 請求，觸發了 CSRF/Session 保護機制，導致跳轉到 `/orders/add` 時畫面上方出現紅字警告：
   > **`入力が無効になりました。最初からやり直してください。`**（輸入已失效，請從頭開始）
   此時 eipro 暫時隱藏了下方所有客戶輸入欄位，讓使用者誤以為搶位失敗或跳到了壞掉的網址！
4. **為什麼 24 秒後又突然出現填表頁？**：使用者在 24 秒後按下了瀏覽器重新整理（F5）。此時所有在途請求早已結束，乾淨的 GET 請求讓 eipro 順利讀出資料庫中的 15 分鐘暫時鎖定狀態，**整張預約表單與 `残り14分55秒` 倒數計時立即完整浮現**！

### 2. v1.0.3 的三大根治與自動修復機制

* **⚡ 機制 1：成功瞬間立即中斷所有在途連線（AbortController）**
  * 一旦有任何一發 `hold_slot` 回傳 `result: 1` 成功，立刻呼叫 `AbortController.abort()` 瞬斷所有正在排隊或傳輸中的後續請求，後端 Session 不再被打架衝突。
* **🛡️ 機制 2：徹底消除表單按鈕重複點擊**
  * 鎖位主軸完全由專屬高速 API 接管，移除連發迴圈中的按鈕點擊；DOM 監控嚴格限制至多觸發單次，徹底杜絕 CakePHP CSRF 衝突。
  * 成功後保留 200ms 緩衝讓 PHP Session 穩固寫入，再乾淨導向 `/orders/add`。
* **🔄 機制 3：預約頁面「自癒防呆自動重整（Self-Healing Auto-Reload）」**
  * 在 `/orders/add` 頁面增加智能偵測：若頁面出現「入力が無効になりました」或「最初からやり直してください」紅字警告，小幫手會立即顯示黃色友好提示 Banner：
    > `🔄 偵測到伺服器暫態 Session 訊號，席位保留依然有效！小幫手正在為您自動重整載入預約表單，請稍候...`
  * 並在 **600ms 內自動替使用者執行乾淨重新整理**（安全上限 2 次防無窮迴圈），瞬間將表單與 15 分鐘倒數計時還原出來！使用者完全不需要手動 F5 驚慌猜測！
* **🎯 機制 4：支援「08:15 首輪釋出撿漏」等任意開賣時間自由自訂**
  * eipro 系統在 08:00 被鎖定的席位若未完成結帳，將在 **08:15:00** 準時釋出回系統池中！
  * 外掛提供快捷晶片按鈕：**`【🕗 08:00 首波】`**、**`【🕣 08:15 釋出撿漏】`**、**`【🕤 08:30 次輪釋出】`**，亦可自由手動填寫任何時間（如 `08:45:00`）。
  * 底層時鐘觸發器全面動態化，不管設定幾點，皆會在 `開賣時間 - 15ms` 毫秒精準發射狙擊！
* **👥 機制 5：船預設人數調整為 3 名（進頁面後可隨時自由更改）**
  * 高千穂峽貸しボート一艘船上限即為 3 名大人。預設人數改為 **3 名**，並在進入 `/orders/add` 頁面時自動幫使用者預選為 3 人。
  * 搶票第一步是搶下「整艘船」，API 不帶人數；進到預約輸入頁面後有整整 15 分鐘，使用者依然可以在下拉選單隨意切換成 1 人或 2 人！
* **🚀 機制 6：極致直覺的「一鍵直達任務就緒卡」與「網頁大字倒數」**
  * Popup 頂部新增大按鈕：**`🚀 一鍵直達預約活動頁面 (自動就緒)`**，一鍵幫使用者開啟並跳轉到正確活動頁，免去手動找網址的煩惱。
  * 網頁右上角 HUD 面板新增**大字動態倒數**（例如 `⏳ 距 08:15:00 開賣倒數：02 分 35 秒`），小於 10 秒變為紅色閃爍警示，讓使用者清楚知道外掛正在就緒倒數！
  * 若使用者停在日曆總覽頁，頁面頂部會自動彈出「👉 一鍵直達目標活動頁」引導橫幅，徹底告別迷路。
* **🕹️ 機制 7：全域持久化「啟動與停止搶位」與多分頁即時同步**
  * **如何停止**：
    1. 在網頁右上角 HUD 面板點擊 **`🛑 停止搶位並釋放資源`**。
    2. 或在工具列 Popup 任務卡點擊 **`🛑 停止搶位`**。
    3. **解決開新分頁又繼續跑的問題**：狀態會立即全域寫入 `chrome.storage`，並透過 `storage.onChanged` 同步通知所有分頁；新開分頁或按 F5 重新整理也會**嚴格維持停止狀態**，絕不擅自重啟！
  * **如何啟動**：
    1. 在網頁右上角 HUD 面板點擊 **`▶️ 啟動搶位監控`**（綠色按鈕）。
    2. 或在工具列 Popup 任務卡點擊 **`▶️ 啟動搶位`**。
    3. 狀態立即變為 `🟢 待命中`，大字毫秒倒數與開賣觸發器全自動就緒！
  * **手動即時搶位**：隨時點擊 **`⚡ 一鍵立即搶位`**，會自動重新啟動並立即送出連發鎖位。

## ⏱️ 網路延遲實測與發送時機解析

* **網路單向傳輸時間（One-way Latency）**：台灣 ⇄ 日本 eipro 伺服器約 **20ms ~ 35ms**。
* **為什麼提早 15ms 是最佳發送點？**
  * 若開賣時間為 `08:00:00.000`，外掛設定在 `07:59:59.985` 發出第一發請求：
    $$\text{07:59:59.985} + \text{20ms (網路耗時)} = \mathbf{08:00:00.005} \quad 🎯$$
  * 封包將於開賣瞬間後 **5 毫秒** 精準抵達伺服器，既避開開賣前的「尚未開放」拒絕，又領先絕大多數人工與其他腳本！
* **250ms 安全重試節奏**：
  * 若伺服器系統時間有微小落後（開賣瞬間前幾毫秒回傳未開放），外掛會以 **250ms 溫和節奏** 重送（最多 12 次，約 3 秒）。
  * 擬真人極限手速，完全不會觸發雲端 WAF 或遭伺服器視為惡意攻擊封鎖 IP。

## 🚀 3 步驟安裝與使用教學

### 步驟 1：載入擴充功能至 Chrome
1. 打開 Chrome 瀏覽器，在網址列輸入並前往：
   ```text
   chrome://extensions/
   ```
2. 開啟右上角的 **「開發人員模式 (Developer mode)」**。
3. 點擊左上角 **「載入未封裝項目 (Load unpacked)」**。
4. 選擇本專案目錄：
   ```text
   /Users/ych/takachiho_crawler/chrome_extension
   ```
5. 確認版本顯示為 **v1.0.3**。
6. 點擊瀏覽器工具列右上角的小拼圖圖示，找到小船圖示並點擊圖釘 📌 固定在工具列。

---

### 步驟 2：確認搶位目標設定（預設即為 11/07 正式）
點擊工具列的小船圖示打開設定面板：

1. **預設已配置為 11/07 正式搶票**：
   * 預設網址已指向 11/07 08:30 船班，若有誤動可點擊：**`🎯 重設為 11/07 正式搶票網址 (點擊自動套用並儲存)`**。
   * 面板會自動同步網址、日期為 `2026/11/07`、時段為 `08:30:00`，並**自動儲存**！
2. **開賣發動時間**：
   * 預設為 `08:00:00`（10/24 早上 8 點首波開賣），提前 15ms（`07:59:59.985`）。
   * 若要搶 8:15 放出之逾期票，可直接點擊 `08:15` 快捷按鈕。
3. 確認黃色預覽文字顯示：
   `🎯 首發發動時間：07:59:59.985（提前 15ms 命中開賣瞬間，未開則 250ms 安全重試）`。

---

### 步驟 3：搶票當天（早上 07:55）標準操作流程（SOP）

1. **07:55 打開專屬活動網址**：
   * 點擊擴充功能選單中的 **「🌐 開啟此目標網址」**（或點擊網址直接前往）。
   * **⚠️ 重要提醒：請務必停留在專屬活動頁面（`events/view/EV00000007?...`），不要停留在日曆週表示頁！**
2. **確認右上角懸浮面板**：
   * 頁面右上角會出現 **【🛶 高千穂峡ボート 搶位助手 v1.0.3】** 面板。
   * 核對面板資訊：
     * **目標時段**：`2026/11/07 08:30`
     * **搶位發動時間**：`07:59:59.985 (提前 15ms)`
     * **Session 代碼**：正常顯示非空白代碼
     * **狀態**：`🟢 待命中`
3. **07:59:59.985 全自動發動**：
   * 當毫秒時鐘倒數至發動時間，助手將自動送出首發請求，並以 250ms 安全重試。
   * 若頁面上出現「予約手続き」按鈕，助手的 MutationObserver 也會同步以 0 毫秒極速自動點擊（雙軌防護）。
4. **搶位成功（15 分鐘保留期啟動）**：

   * 頁面將在 0.3 秒內自動帶入同 Session 進入 `orders/add` 預約輸入頁！
5. **悠閒填寫資料並送出**：
   * 進入預約頁面後，畫面上方會顯示倒數 `残り14分59秒`。
   * 請在電腦前從容填寫代表者姓名、電話、地址、人數與信用卡資料。
   * 點擊「入力確認」送出後，若跳轉至銀行 3D 簡訊驗證頁面，輸入手機驗證碼即可完成訂位！

## 🛠️ 除錯日誌匯出與問題排除指南

若操作過程中遇到任何疑慮，請依照以下步驟匯出 Log 記錄：

1. **如何下載 Log 檔案**：
   * **方式 A（推薦）**：點擊 Chrome 工具列的小船圖示，展開底部的「📋 執行日誌與除錯」，點擊 **`📥 下載 .log 檔案`**。
   * **方式 B**：在預約網頁右上角助手面板中，展開「📋 即時除錯日誌」，點擊 **`📥 匯出 .log 檔案`**。
   * 產生的檔案名稱如 `takachiho_helper_20261012_215500.log`，會直接存入「下載項目」資料夾。
2. **常見訊息說明**：
   * `result=1`：🎉 席位鎖定成功！
   * `予約枠が存在しません`：Session 代碼與該日期時間不符，或該時段不存在。請點擊切換按鈕重新帶入相符時段。
   * `予約が定員数に達しています`：該時段已被其他人在毫秒間搶購一空（額滿）。
   * `この枠は予約受付が開始されていません`：伺服器尚未開放預約（代表尚未到 08:00:00.000）。
