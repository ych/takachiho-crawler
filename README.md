## 🚀 監控機制與特點

1. **先暫存比對**：
   * 每次抓取網頁原始 HTML 會先寫入暫存區 (`temp/latest_temp.html`)。
2. **智慧正規化比對（避免誤報）**：
   * eipro.jp 每次載入時會自動刷新 `action_token` (隨機 CSRF token) 與靜態資源的 `cache=時間戳記`。
   * 本工具會先濾除這些無關內容的動態雜訊，只針對 **實質網頁內容、表單欄位、狀態按鈕、錯誤提示** 進行比對。
3. **實質異動永久存檔**：
   * 當偵測到網頁內容有變動時（例如：開放預約按鈕出現、表單欄位載入），立即將完整 HTML 存檔至 `snapshots/snapshot_YYYYMMDD_HHMMSS.html`。
   * 自動產生 `.patch` 差異比較檔至 `diffs/`。
   * 發出終端警報聲（`\a` 嗶聲）提醒您。
4. **自動解析表單結構**：
   * 自動提取頁面中所有的 `<form>`、`<input>`、`<select>` 欄位名稱與屬性，輸出為 `snapshot_YYYYMMDD_HHMMSS_parsed.json`。
5. **整合時段 API 狀態查詢**：
   * 同步查詢 eipro 內部的 `service_unit` API，直接辨識目前狀態：
     * ⏳ `hourglass`：未開放（預約準備中）
     * ⭕ `circle`：開放預約中！
     * ❌ `times`：已售完／預約結束
   * 當時段由沙漏轉為開放時，自動嘗試抓取並存檔預約輸入頁面 (`orders/add`)。

## 💻 常用執行指令

請先進入目錄：
```bash
cd /Users/ych/takachiho_crawler
```

### 1. 測試執行單次比對
```bash
python3 crawler.py --once
```
* 若內容無變動：顯示 `✅ 比對結果：與先前快照內容一致（無實質變更）。`
* 若有變動或初次執行：自動存下快照與表單分析。

---

### 2. 即時查詢目前時段 API 狀態
```bash
python3 crawler.py --status
```
直接輸出該時段目前是沙漏 ⏳ 還是可預約 ⭕。

---

### 3. 明天早上 08:00 定時監控（建議方式）

可以在 **明天早上 07:55** 啟動高頻輪詢（例如每 3 秒檢查一次）：
```bash
python3 crawler.py --interval 3
```

或者使用內建的自動定時啟動功能，設定在 **07:59:50** 自動開始輪詢：
```bash
python3 crawler.py --start-at 07:59:50 --interval 2
```

---

### 4. 發現異動並存檔後自動停止
```bash
python3 crawler.py --interval 3 --stop-on-change
```

## 📝 預約必備資料（根據高千穂觀光協會規定）
預約表單開放時需填寫代表者資料：
1. **代表者姓名**（漢字與片假名）
2. **電子郵件信箱**（需接收確認信）
3. **聯絡電話**
4. **住址**
5. **代表者出生年月日**
6. **搭乘人數**（小學生以上算大人，1 艘船上限 3 名大人；含學齡前幼童最多 4 名）
7. **信用卡付款**（支援 Visa, MasterCard, JCB, Amex, Diners，需 3D 驗證）
